# Сайт СуперВеб

Статический сайт: обычные HTML, CSS и JavaScript, без систем сборки и фреймворков.
Опубликован через GitHub Pages на домене **superweb.ru**.

## Где что лежит

| Файл или папка | Что это |
|---|---|
| `index.html` | Главная страница |
| `cases.html` | Кейсы участников по потокам |
| `grad.html` | Фотографии с выпускных |
| `student.html` | Проверка сертификата участника |
| `assets/css/styles.css` | Все стили сайта |
| `assets/js/app.js` | Скрипты: лайтбокс, ленты, фильтры, поиск сертификата |
| `assets/img/` | Все изображения |
| `CNAME` | Домен сайта, трогать не нужно |
| `.nojekyll` | Служебный файл GitHub Pages, трогать не нужно |
| `build-preview.ps1`, `serve.ps1` | Вспомогательные скрипты, на сайт не попадают |

## Как внести изменение

### Способ 1: в браузере (проще всего для текста)

1. Открыть `https://github.com/msmasha66-ux/superweb`
2. Нажать на нужный файл, затем на карандаш справа сверху.
3. Поправить текст.
4. Внизу страницы нажать **Commit changes**.

Через 1–3 минуты правка появится на сайте.

### Способ 2: на компьютере

1. Открыть папку с исходниками, поправить файлы любым редактором.
2. В **GitHub Desktop** слева внизу написать краткое описание правки и нажать **Commit to main**.
3. Вверху нажать **Push origin**.

### Как заменить фотографию

1. Положить новый файл в нужную папку внутри `assets/img/`.
2. В HTML найти старое имя файла и заменить на новое (имя встречается дважды: в `href` и в `src`).
3. Опубликовать одним из способов выше.

Размеры: фотографии галерей — около 900–1400 px по ширине, полноразмерные версии
для увеличения лежат в `assets/img/grad/full/`.

## Что важно знать

- **Домен.** `superweb.ru` ведёт на GitHub Pages четырьмя A-записями
  (185.199.108.153, .109, .110, .111) и CNAME для `www` на `msmasha66-ux.github.io`.
  Записи MX и TXT в DNS отвечают за почту, их менять нельзя.
  `course.superweb.ru` ведёт на GetCourse, там выдаются сертификаты.
- **Проверка сертификата** на странице `student.html` обращается к базе
  `salebot-help.ru`, которая принимает запросы только с адреса `https://superweb.ru`.
  На других адресах поиск выдаёт ошибку — это ожидаемо.
- **Автоперевод отключён** мета-тегом `notranslate`: иначе браузер подменял
  названия брендов («Wildberries» превращался в «Wildberry»).
- **Резервная копия.** Сайт хранится в двух местах: папка на компьютере и
  репозиторий GitHub. История всех версий — на вкладке History в GitHub Desktop,
  любую правку можно откатить.
